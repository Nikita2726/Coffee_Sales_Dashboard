# ☕ Coffee Shop Sales Analysis

## 📌 Project Overview

This project analyzes coffee shop sales data using **Microsoft Excel** to identify sales trends, customer purchasing patterns, product performance, and store-level performance.

The project uses **Pivot Tables, data cleaning, calculated fields, and an interactive Excel Dashboard** to transform raw transaction data into meaningful business insights.

---

## 🎯 Objectives

The main objectives of this project are to:

* Analyze overall coffee shop sales performance
* Identify the best-performing products and product categories
* Compare sales across different store locations
* Analyze sales trends by month and day
* Identify peak sales hours
* Understand customer purchasing patterns
* Create an interactive dashboard for business reporting

---

## 📊 Dataset

The dataset contains approximately **149,000+ sales transactions**.

### Key Columns

| Column             | Description                    |
| ------------------ | ------------------------------ |
| `transaction_id`   | Unique transaction identifier  |
| `transaction_date` | Date of transaction            |
| `transaction_time` | Time of transaction            |
| `store_id`         | Store identifier               |
| `store_location`   | Store location                 |
| `product_id`       | Product identifier             |
| `transaction_qty`  | Quantity purchased             |
| `unit_price`       | Price per unit                 |
| `product_category` | Product category               |
| `product_type`     | Type of product                |
| `product_detail`   | Detailed product name          |
| `Size`             | Product size                   |
| `Total_bill`       | Total transaction amount       |
| `Month Name`       | Month of transaction           |
| `Day Name`         | Day of transaction             |
| `Hour`             | Transaction hour               |
| `Day of Week`      | Numerical day representation   |
| `Month`            | Numerical month representation |

## 📈 Analysis Performed

### 1. Sales Analysis

Analyzed:

* Total sales
* Total transactions
* Total quantity sold
* Average transaction value
* Sales distribution across products

### 2. Product Analysis

Identified:

* Top-selling products
* Product categories generating the most revenue
* Product types with high transaction quantities
* Product size preferences

### 3. Store Analysis

Compared sales performance between different store locations to understand:

* Store-level revenue
* Transaction volume
* Product demand
* Differences in customer purchasing patterns

### 4. Time-Based Analysis

Analyzed sales according to:

* Month
* Day of week
* Hour of day
* Peak business hours

This helps identify periods of high and low customer activity.
